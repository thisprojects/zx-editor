AY-3-8912 Music Export

Playing a tracker song exported from the Music Editor on real Z80 hardware
pasmo --tapbas music.asm music.tap  |  fuse music.tap

What gets exported

Export ASM in the Music Editor produces a single, self-contained .asm file — no incbin, nothing else to assemble alongside it. It contains:

  • A 96-entry AY tone-period table (12 semitones × 8 octaves), computed for the AY-3-8912's 1.7734MHz clock on the 128K.
  • One 16-step volume envelope per instrument, plus its loop point.
  • Pattern data: 5 bytes per row per channel (note, instrument, volume, effect, effect param).
  • An order table chaining patterns into a song.
  • A complete player routine: music_init and music_tick.

The note/instrument/volume columns are fully played back. The effect and per-instrument noise columns are exported for reference but not interpreted by the reference player — extend music_tick if you want arpeggio/slide/noise support in your own player.

Wiring it into your program

The exported file is already a runnable program on its own (entry point start, assembled at $8000, runnable via RANDOMIZE USR 32768). To use it inside a bigger game or demo instead, drop the start/halt_loop block and call the two player entry points directly from your own main loop: 

        include "music.asm"

        org     $8000
my_start:
        call    music_init      ; once, at program start
my_loop:
        halt                    ; wait for 50Hz vsync
        call    music_tick      ; advance playback by one frame
        ; ... your game code ...
        jr      my_loop

music_tick only ever writes to the AY's own registers (via $FFFD/$BFFD on the 128K) — it doesn't touch the screen, stack depth beyond a few pushes, or any system variables, so it's safe to call once per frame alongside your own rendering and game logic.

Register format reference

ByteMeaning
note0–95 = index into period_table (octave*12 + semitone), $FF = no event, $FE = note off
instrumentindex into the song's instrument list, $FF = none
volume0–15 fixed volume, $FF = use the instrument's envelope
effect / paramexported for reference only in v1 (0=none, 1=arpeggio, 2=slide up, 3=slide down)

Assembling and running

pasmo --tapbas music.asm music.tap
fuse music.tap

In Fuse, type RANDOMIZE USR 32768 and press Enter once the tape has loaded to start playback (or use fuse --auto-load music.tap to skip straight to running it).

See examples/music/music_player_demo.asm in this repository for a complete hand-written reference track using the same data layout and player routine described above.
